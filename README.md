
# LeaveHub - PKB Staff Management System

## About
LeaveHub is a web-based staff management system
developed for Permodalan Kedah Berhad (PKB).

## Technologies
- Java
- JSP
- Java Servlets
- MySQL
- HTML
- CSS
- JavaScript
- Apache Tomcat
- Eclipse IDE

## Main Modules

### Staff Portal
- Staff Dashboard
- Leave Applications
- Leave Balance
- Leave Calendar
- Attendance Records

### Administration
- Staff Management
- Leave Approval
- Attendance Management
- Inventory Management
- Vehicle Management
- Medical & Dental Management
- Announcements
- Company Events
- Audit Trail

## Database
MySQL database.

Refer to the database documentation
for setup instructions.

## Development Environment
- Eclipse IDE
- Apache Tomcat 10.1
- XAMPP / MySQL

## Installation
1. Clone this repository.
2. Import the project into Eclipse.
3. Configure Apache Tomcat.
4. Configure MySQL database credentials.
5. Import the approved database schema.
6. Run the application on Tomcat.

## Security
Do not upload actual database credentials,
staff personal information, or confidential
company records.
